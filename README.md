An entry for the [The Comment Above the Code](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026) bounty on [make.fun](https://make.fun): write the funniest comment a developer left above a line of code.

## The entry

> // I kept the sleep(500) in sendReceipt() because without it the printer in aisle 3 prints every invoice twice.

A code comment confessing to a magic sleep(500) that nobody dares remove — because the printer in aisle 3 prints every invoice twice without it. One concrete function name (sendReceipt), one concrete detail (aisle 3), and the weary pragmatism every developer recognises. 111 characters.

## Run

```sh
node main.ts
```

Writes the single-line comment to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). Node 22 stdlib only, no dependencies.
